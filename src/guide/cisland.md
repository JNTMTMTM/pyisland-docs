# cisland
本文档为 **cisland(高性能)** 分支教程,功能介绍见[cisland](/branches/cisland.html)

## 展开触发
页面结构
:::info
|名称|操作|备注|
|---|---|---|
|默认|覆盖展开|鼠标移至**最上方**时展开,拖动**回弹**|
|音乐|单点查看详情|**仅在**捕获到音乐播放时支持切换,[详见歌词捕获](#歌词捕获)|
|Ai|单点展开聊天|需要在**设置里面配置**,[详见AI 配置](#ai-配置)|
|sadb|单点手机投屏|[详见手机投屏](#手机投屏)|
:::

**切换页面都是双击切换,如默认页至ai页,默认页至音乐页**
## 条件触发
最高级显示,队列处理
:::info

|名称|操作|备注|
|---|---|---|
|新邮件提示|单击查看|**仅在**配置IMAP后实现,[详见邮箱配置](#邮箱配置)|
|剪切板捕获链接|单点跳转对应链接|**仅在**设置的剪切板中打开剪切板监听时实现|
|Hooks|单击忽略|需要在安装对应的hooks后实现,[详见Code Agent Hooks](#hooks)|

:::
## 歌词捕获
源码实现见[Lyrix](https://github.com/cXp1r/Lyrix)
流程:进程匹配对应api,通过smtc信息搜索并获取歌词
**原生支持** *汽水音乐,QQ音乐* **插件支持** *网易云音乐* **暂不支持** *酷狗音乐(无时间轴)*
:::tip
如果 **原生支持** 中的播放器**时间轴,歌词切换失效**,那么可以考虑**更新**播放器
:::

## 手机投屏
:::warning
**问这个开发人员是不会理你的**
:::
<br>

- 打开手机的开发者模式,不会上网搜 **xx手机如何打开开发者模式**
- 打开手机的开发者模式,不会上网搜 **xx手机如何打开开发者模式**
- 打开手机的开发者模式,不会上网搜 **xx手机如何打开开发者模式**
- **进入开发者选项**
- **找到调试**
### 有线投屏
- 打开 'USB 调试'
- 使用***数据线***连接电脑
- 在弹出的对话框中勾选 **一律允许使用这台计算机进行调试(不同厂商可能不一样)**
- 点击允许
### 无线投屏
- 打开 '无线调试'
![手机](/cisland/0.png)
![电脑](/cisland/1.png)
:::tip
**无线调试每次换wifi需要重新打开,不如直接usb调试**
:::


## 邮箱配置
**前往下方链接获取对应的**
- 邮箱地址
- 密码/授权码
- IMAP 服务器地址
- SSL端口号

[qq邮箱官方教程](https://wx.mail.qq.com/list/readtemplate?name=app_intro.html#/agreement/authorizationCode)
[163邮箱官方教程](https://help.mail.163.com/faqDetail.do?code=d7a5dc8471cd0c0e8b4b8f4f8e49998b374173cfe9171305fa1ce630d7f67ac2a5feb28b66796d3b)
其他邮箱可以自行上网搜索

**前往设置->邮件->按照提示填入即可**

## 日志&配置路径
硬编码路径:%appdata%\dynamic-island

:::tip
如需反馈bug,请提供路径**%appdata%\dynamic-island\log**下最后一篇日志
例:island_1775838435105.log,**结尾数字越大说明越新**
:::
